# Research script examples

These user-provided research scripts are included unchanged (filenames simplified) for code review. They are separate from the standalone numerical demo and are not imported or executed by it.

- `metalens_postprocessing_example.py`: Lumerical field extraction, field projection, focal cuts, power integration, exploratory wavefront analysis, and MAT export.
- `phase_to_sag_example.py`: exploratory phase extraction and an equivalent-sag array export. This does not establish a validated Zemax import workflow.

## Execution requirements
Ansys Lumerical FDTD with a valid license, its matching lumapi installation, the referenced FSP file, lookup-table text files and monitor names, plus NumPy, SciPy, Matplotlib and scikit-image. Local installation paths and filenames are research-machine settings. None of the FSP or lookup-table inputs is bundled. These scripts were not executed for this portfolio release.

## Interpretation of exploratory sections
The original scripts preserve research-stage calculations: sums of vector components do not define a general total-field phase; near-field integration axes need verification; focal-power sampling and the integration radius need convergence checks; focal-plane phase subtraction is not a validated pupil-wavefront aberration analysis. The Zernike fitting call is commented out. These sections document work in progress and are not presented as validated efficiency or aberration results. No demo figure is generated by these scripts.
